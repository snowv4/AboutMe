# AboutMe

Portfólio de Victor Sant’Ana Ramos sobre desenvolvimento de software, sensores vestíveis e automação industrial.

## Abrir o site

[Ver o portfólio](https://snowv4.github.io/AboutMe/)

O site usa HTML, CSS e JavaScript. Para visualizar localmente, abra o arquivo `index.html` no navegador. O texto em português fica no HTML e as traduções em inglês, espanhol e alemão ficam em `locales.js`.

## Publicar alterações

O GitHub Pages serve a raiz da branch `gh-pages`. Após integrar mudanças na `main`, faça um fast-forward de `gh-pages` para o commit revisado. O GitHub publica a atualização automaticamente.
